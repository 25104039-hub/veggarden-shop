# VegGarden 🥬

A mobile-first online vegetable shop for South Indian produce — 16 vegetables with
cute product photos, English **and** Tamil names, today's cheap rate shown next to
the usual shop price, search, basket and checkout.

> The prices in this repo are **sample data** so the shop looks alive. Swap in your
> real rates (or a live feed) before going public — see *Changing the prices* below.

## Features

- **16 South Indian vegetables** — tomato, brinjal, vendhaya keerai, pudalangai,
  drumstick, raw banana, bitter gourd, yam, colocasia, shallots and more, each with
  a Tamil script name, a spoken transliteration and a cooking note (poriyal, kootu,
  sambar, payasam…).
- **Search that understands how people actually talk** — try `keerai`, `pudalangai`,
  `bitter`, or `sambar`. It matches English names, Tamil script, transliterations and
  dishes.
- **Today's deal** banner that always surfaces the biggest percentage saving.
- **Basket & checkout** — quantity steppers, savings vs shop prices, free-delivery
  progress bar, delivery pin and time slot, order confirmation.
- **Order history** — past orders with one-tap reorder.
- **Works offline-ish** — the basket is saved in the browser, so a refresh never
  loses the order.
- **No backend needed** — pure front end, deploys anywhere as a static/edge app.

## Run it locally

You need [Bun](https://bun.sh) (or Node.js 20+ with npm).

```sh
bun install
bun run dev
```

Then open http://localhost:8080. With npm instead: `npm install && npm run dev`.

Build for production: `bun run build` (output in `dist/`).

## Changing the prices

Everything the shop sells comes from one array in `src/data/vegetables.ts`. To add a
vegetable, edit a price, or change the Tamil name, touch that one file — the cards,
search, deal banner and basket all read from it.

```ts
{
  id: "tomato",
  name: "Tomato",
  tamil: "தக்காளி",
  tamilRoman: "Thakkali",
  use: "Sambar, rasam, thoran",
  category: "staples",
  badge: "deal",
  price: 28,      // today's rate
  mrp: 40,        // usual shop price (shown struck through)
  unit: "kg",
  image: tomato,
  tint: "bg-tint-rose",
}
```

## Notes

- Delivery is a flat ₹15, free above ₹199, and quantities cap at 20 — all constants
  in `src/lib/shop.tsx`.
- `src/routeTree.gen.ts` is generated by the router plugin; never edit it by hand.
